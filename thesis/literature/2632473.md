# Mulvey & Vladimirou (1992) — *Stochastic Network Programming for Financial Planning Problems*

- **PDF:** `2632473.pdf`
- **Venue:** *Management Science*, Vol. 38, No. 11 (Focused Issue on Financial Modeling), pp. 1642–1664.

## Methodology (Monte Carlo variant used)
**Multistage stochastic generalized network programming (MSN)** for
dynamic financial planning problems. Uncertainty in asset returns,
borrowing rates and external deposit / withdrawal streams is encoded as
a finite scenario set $S$ with probabilities $\pi_s$, organised on a
**scenario tree**. Nonanticipativity is imposed explicitly via "split
variable" constraints that equate decisions across scenarios sharing
the same information history.

The optimisation problem is solved with the **progressive hedging
algorithm** of Rockafellar and Wets (1991), which dualises the
nonanticipativity constraints and decomposes the program into
scenario-wise generalized-network subproblems.

Monte Carlo enters **at the scenario-generation stage only**: scenarios
of returns and rates are sampled from posited stochastic processes, then
treated as a discrete tree. The pricing / optimisation step itself is
deterministic per scenario.

## Type of data
- **Synthetic** scenarios constructed from stochastic models of asset
  returns and rates.
- **Empirical** asset-allocation case study uses historical statistical
  inputs (means, variances, correlations).

## Computational setup
Decomposition is explicitly designed to enable **parallel computation**
across scenario subproblems. The authors and Vladimirou and Mulvey
(1991) reference parallel implementations on multiprocessor architectures
of the era. No Spark / MapReduce — this is pre-Hadoop work, but it is an
early instance of using parallelism in financial planning.

## Key contribution
- Casts portfolio selection, international cash management and
  programmed-trading arbitrage as multistage stochastic *generalized
  networks*, exploiting graph structure to keep subproblems tractable.
- Adopts the progressive-hedging algorithm — at that time recent — for
  large-scale decomposition, demonstrating empirical benefits on an
  asset-allocation case.

## Strengths
- Unified framework covering several distinct financial-planning
  problems with the same network abstraction.
- Decomposition preserves the network structure of each subproblem,
  enabling specialised, efficient solvers.
- Pioneer of the scenario-tree / nonanticipativity formalism that
  underlies most modern stochastic programming for finance.

## Limitations
- Computational cost grows multiplicatively with depth of the scenario
  tree and number of realisations per stage; only modest cases are
  tractable in the original work.
- Scenario generation itself is left as an exogenous Monte Carlo task,
  with no integration of variance-reduction or quasi-MC techniques.
- The model is linear (or piecewise-linear) in transaction costs; non-
  linear costs or jumps require extensions.
- Hedging applications and option payoffs (path-dependent, American)
  fall outside the framework as presented.
